# Test fixtures

`drafts/` is a fictional held-drafts folder in the same layout as the gitignored
`.drafts/` (see Held drafts in `_docs/APPS.md`). `_tests/run.py` installs it in
every temporary copy, so the suite exercises drafts the same way in a fresh
clone and on a machine with real drafts. Every product, line, and image here
is an example; none of it is unconfirmed product copy.

- `samplenote`: a lab draft product with four phone screenshots and a dark color
- `sampleboard`: a live draft web product with three wide screenshots
- held lines for `nookly` and `quorum`
